# Mon site web

Site statique simple (HTML / CSS / JS), sans outil de build.

## Voir le site en local

Ouvre `index.html` dans un navigateur, ou lance un petit serveur :

    python3 -m http.server 8000

puis va sur http://localhost:8000.

## Structure

- `index.html` – contenu de la page
- `style.css` – mise en forme (clair / sombre automatique)
- `script.js` – petits comportements JavaScript

## Mise en ligne

Avec GitHub Pages : Settings → Pages → « Deploy from a branch » → `main` / racine.
